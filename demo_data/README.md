# Demo Data

This directory contains sample fixtures and scripts for demonstrating TracePilot.

- `sample_job_card.json` - Sample job card for a Precision Shaft Assembly
- `sample_specs.json` - Five critical specifications with tolerances
- `sample_steps.json` - Inspection steps linked to specifications
- `generate_demo_pdf.py` - Script to generate synthetic PDF documents for testing

Run `python generate_demo_pdf.py` from this directory to create the demo PDFs.
